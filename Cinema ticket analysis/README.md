# Cinema Ticket Analysis

A SQL practice project built around a fictional cinema ticketing dataset.

## Purpose

This project consolidates foundational SQL skills through practical data analysis before moving into more advanced topics such as JOINs.

## Skills Practiced

* Database and table creation
* Data types and constraints
* SELECT and WHERE
* Filtering with multiple conditions
* ORDER BY
* Aggregate functions
* GROUP BY
* HAVING
* NULL handling
* Date and time filtering
* Basic revenue and ticket analysis

## Database

SQL Server
